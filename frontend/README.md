# Riffat Jabeen — Portfolio (Frontend)

React + Vite + Tailwind CSS + Framer Motion.

## Setup

1. Install [Node.js LTS](https://nodejs.org) (v18+) if you don't have it.
2. Install dependencies:
   ```
   npm install
   ```
3. Run the dev server:
   ```
   npm run dev
   ```
4. Build for production:
   ```
   npm run build
   ```

## Content

All resume content (experience, skills, projects, education, contact info) lives in
[src/data/profile.js](src/data/profile.js) — edit that file to update the site, no need
to touch components.

## Deploy

Push this folder to GitHub and import it into [Vercel](https://vercel.com) as a Vite project
(root directory: `frontend`). No environment variables needed yet.
